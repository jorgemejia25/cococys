Concepto fundamentalDefinición recursiva

Un árbol contiene árboles más pequeños.

Raíz

Nodo distinguido que sirve como punto de entrada.

Subárboles

Los nodos restantes se dividen en conjuntos disjuntos que también son árboles.

La definición es recursiva: cada hijo puede verse como la raíz de otro árbol.

Medidas del árbolNo son sinónimos

Nivel, profundidad y altura miran en direcciones opuestas.

Nivel / profundidad

Aristas desde la raíz hasta el nodo. La raíz está en nivel 0.

Altura de un nodo

Camino más largo desde ese nodo hasta una hoja.

Altura del árbol

Altura de su raíz. Una hoja tiene altura 0.

profundidad(E) = 2 · altura(E) = 0 · altura(A) = 2
PropiedadesÁrbol binario

Sin ciclos, cada nodo nuevo aporta una arista.

n nodos → n − 1 aristas
máximo en nivel k → 2ᵏ
máximo con altura h → 2^(h+1) − 1
altura mínima → ⌊log₂ n⌋
Entre dos nodos existe un único camino. Si hubiera dos, aparecería un ciclo y dejaría de ser un árbol.
Formas comunesLa forma afecta el costo

Tener los mismos datos no implica tener el mismo árbol.

Lleno

Cada nodo tiene exactamente cero o dos hijos.

Completo

Los niveles se llenan de izquierda a derecha.

Degenerado

Cada nodo tiene un solo hijo; se comporta como una lista.

La altura mínima favorece las operaciones; la forma degenerada elimina la ventaja de búsqueda.

Enlaces o arregloElegir según la forma

Un arreglo funciona bien cuando casi no existen huecos.

izquierdo(i) = 2i + 1
derecho(i) = 2i + 2
padre(i) = ⌊(i − 1) / 2⌋

Regla práctica

La representación por arreglo conviene para árboles completos, como un heap. En árboles ralos desperdicia espacio; usa nodos enlazados.

Implementación C#Nodo genérico

El tipo del dato cambia; la estructura permanece.

public class Nodo<T> where T : IComparable<T>
{
    public T Dato { get; set; }
    public Nodo<T>? Izquierdo { get; set; }
    public Nodo<T>? Derecho { get; set; }
    public int Altura { get; set; } = 0;

    public Nodo(T dato) => Dato = dato;
}
Implementación C#Búsqueda iterativa

CompareTo decide qué subárbol descartar.

public bool Buscar(T dato)
{
    Nodo<T>? actual = raiz;
    while (actual != null)
    {
        int cmp = dato.CompareTo(actual.Dato);
        if (cmp == 0) return true;
        actual = cmp < 0 ? actual.Izquierdo : actual.Derecho;
    }
    return false;
}
Árbol AVLABB autoequilibrado

El AVL impide que la altura crezca como una lista.

Conserva

El mismo invariante de orden de un ABB.

Añade

Una condición de balance revisada después de insertar o eliminar.

altura(v) = 1 + max(altura(izq), altura(der))
altura(null) = −1 · altura(hoja) = 0
Medir el balanceFactor de equilibrio

El signo indica qué lado pesa más.

FE(v) = altura(izq(v)) − altura(der(v))

FE > 0

Pesa el subárbol izquierdo.

FE = 0

Ambos lados tienen la misma altura.

FE < 0

Pesa el subárbol derecho.

Es AVL si |FE(v)| ≤ 1 para todos los nodos.
Complejidad garantizadaAltura logarítmica

Balancear convierte el mejor escenario en garantía.

N(h) = 1 + N(h−1) + N(h−2)
N(h) = F(h+3) − 1
h ≤ 1.4405 log₂(n+2) − 0.3277
h = O(log n)
Buscar, insertar y eliminar permanecen en O(log n), incluso en el peor caso.
