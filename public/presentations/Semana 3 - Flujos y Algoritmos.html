Pensamiento sistémico

Capacidad de ver los componentes individuales como partes interdependientes de un sistema mayor y coherente.

▹No basta saber «qué es la RAM» o «qué es un router» por separado.
▹Hay que preguntar: ¿con quién habla? y ¿qué pasa si falla?.

op
Hardware de procesamientoBASE

¿Qué es una instrucción?

Una orden mínima que la CPU sabe ejecutar: sumar, copiar un valor, saltar a otra dirección.

1El programa es una lista de instrucciones.
2Cada instrucción tiene un código (opcode) y a veces datos.
3El «vocabulario» de instrucciones se llama conjunto de instrucciones (ISA).
RISC
Tecnologías RISC / CISCRISC

RISC — pocas órdenes, simples

Reduced Instruction Set Computer: conjunto reducido. Cada instrucción hace poco, pero se ejecuta muy rápido y de forma predecible.

▹Pocas instrucciones, casi todas del mismo tamaño.
▹Ideal para pipelines: varias instrucciones «en cadena».
▹Ejemplos familiares: muchos chips ARM (celulares, Mac M-series).
CISC
Tecnologías RISC / CISCCISC

CISC — muchas órdenes, potentes

Complex Instruction Set Computer: conjunto complejo. Una sola instrucción puede hacer mucho trabajo (varios accesos a memoria, operaciones combinadas).

▹Muchas instrucciones; algunas son largas y especiales.
▹Históricamente: menos código en memoria (importante cuando la RAM era cara).
▹Ejemplo clásico: familia x86 de PCs (Intel / AMD de escritorio).
vs
Tecnologías RISC / CISCCOMPARACIÓN

RISC frente a CISC

RISC
  • Instrucciones simples y uniformes
  • Más instrucciones por tarea compleja
  • Hardware interno más «limpio»
  • Muy usado en móviles y servidores eficientes
CISC
  • Instrucciones ricas y variables
  • Menos instrucciones por tarea compleja
  • Decodificación más elaborada
  • Dominante en PCs de escritorio x86

Hoy la frontera se difumina: chips CISC modernos internamente rompen instrucciones en micro-operaciones parecidas a RISC.

mem
Hardware de almacenamientoDESDE CERO

¿Para qué sirve la memoria?

La CPU no puede «pensar» sin un lugar donde guardar el programa y los datos mientras trabaja — y otro lugar para guardarlos cuando apagas.

APrincipal: lo que la CPU usa ahora (RAM).
BSecundaria: lo que debe sobrevivir (disco / SSD).
!Si confunden ambas, no entenderán por qué «cerrar el navegador libera RAM» pero «borrar un archivo libera disco».
RAM
Memoria principalVOLÁTIL

Memoria principal (RAM)

Qué es
Almacén de trabajo de la CPU: programas abiertos y datos en uso.
Volátil
Al cortar la energía, se pierde el contenido.
Acceso
La CPU la lee/escribe por el bus usando direcciones.

Analogía: el escritorio. Lo que está encima se usa ya; al apagar, se limpia. El archivero es el disco.

SSD
Memoria secundariaPERSISTENTE

Memoria secundaria

Almacenamiento permanente: HDD, SSD, USB, tarjetas SD. Conserva datos sin energía.

▹Más lenta que la RAM, pero mucho más capacidad y barata por GB.
▹El sistema operativo carga programas del disco a la RAM para ejecutarlos.
▹SSD (estado sólido) es más rápida que HDD (discos mecánicos).

net
Hardware de comunicaciónDESDE CERO

La computadora también habla con el mundo

Hasta ahora: CPU y memoria. Ahora: cómo se conecta a otras máquinas y a Internet.

1Tarjeta de red (NIC) — el «puerto» de la PC.
2Switch / Router / AP — el camino entre dispositivos.
3Firewall — el filtro de seguridad.
NIC
Hardware de comunicaciónNIC

Tarjeta de red (NIC)

Network Interface Card: convierte datos del computador en señales que viajan por cable (Ethernet) o Wi-Fi.

▹Tiene una dirección física MAC única.
▹Puede ser un chip soldado en la placa o un adaptador USB.
▹Sin NIC (o Wi-Fi equivalente), la PC no participa en la red.
Hardware de comunicaciónSWITCH · ROUTER

Switch y router — no son lo mismo

Switch
Conecta equipos de la misma red local (oficina, lab). Reenvía tramas entre puertos según dirección MAC. Piensa: «repartidor interno».
Router
Une redes distintas (tu casa e Internet). Decide rutas con direcciones IP. Piensa: «puerta hacia afuera».

El «modem/router» casero suele mezclar ambas funciones en una sola caja — por eso confunde. En clase las separamos.

AP
Hardware de comunicaciónACCESS POINT

Access Point (AP)

Punto de acceso Wi-Fi: convierte la red cableada en red inalámbrica para laptops y celulares.

▹Los clientes se asocian al AP con SSID y clave.
▹El AP suele conectarse a un switch o router por cable.
▹Muchos routers domésticos incluyen AP integrado.
FW
Hardware de seguridadFIREWALL

Firewall y HW de seguridad

Un firewall filtra el tráfico según reglas: qué entra, qué sale, qué se bloquea. Puede ser software o un aparato dedicado.

▹Decide permitir o denegar conexiones (puertos, IPs, protocolos).
▹Otros HW: IDS/IPS, proxies, UTM — capas adicionales.
▹Pensamiento sistémico: la seguridad es un subsistema que afecta a toda la red.

bus
Buses del sistemaDESDE CERO

¿Qué es un bus?

Un conjunto de líneas eléctricas (o caminos lógicos) por donde viajan señales compartidas entre CPU, memoria y periféricos.

▹Analogía: una carretera con carriles especializados.
▹Hay tres carriles clave: datos, direcciones y control.
▹Si el bus satura, toda la máquina siente el «cuello de botella».
BusesDATOS · DIRECCIÓN · CONTROL

Tres buses, tres trabajos

Bus de datos
Transporta los valores: números, instrucciones, resultados. Bidireccional.
Bus de dirección
Indica dónde leer o escribir en memoria. Va de la CPU hacia afuera.
Bus de control
Señales de mando: leer, escribir, reloj, interrupciones.
