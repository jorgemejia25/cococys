Métodos algorítmicosDefinición

Definición de algoritmo

Conjunto finito, ordenado y preciso de instrucciones que recibe datos de entrada, ejecuta operaciones y produce una salida para resolver un problema.

Entrada

Datos iniciales requeridos por el procedimiento.

Salida

Resultado obtenido después de ejecutar las instrucciones.

entrada → proceso → salida
Conceptos relacionadosAlgoritmo y programa

Diferencia entre algoritmo y programa

Algoritmo

Descripción lógica de una solución. Es independiente del lenguaje y de la plataforma.

calcularPromedio(datos)

Programa

Implementación del algoritmo mediante instrucciones válidas para un lenguaje.

double promedio = suma / n;

Métodos algorítmicosUso de algoritmos

Aplicaciones de los algoritmos

Búsqueda

Localización de datos dentro de una colección.

Ordenamiento

Organización de elementos según un criterio.

Cálculo

Obtención de resultados numéricos o lógicos.

Control

Selección de acciones según el estado de un sistema.

CaracterísticasFinito

Característica finita

El algoritmo termina después de ejecutar una cantidad limitada de instrucciones.

Inicio

Punto de entrada del procedimiento.

Progreso

Actualización de variables o condiciones durante la ejecución.

Terminación

Condición que detiene el procedimiento.

contador ← 1
Mientras contador ≤ 5
    Escribir contador
    contador ← contador + 1
FinMientras
CaracterísticasDefinido

Característica definida

Cada instrucción especifica una operación sin ambigüedad. La misma entrada produce la misma salida bajo las mismas condiciones.

INSTRUCCIÓN AMBIGUA“Ordene los números de una manera conveniente”.
INSTRUCCIÓN DEFINIDA“Ordene los números de menor a mayor”.

Precisión

Operación, datos y criterio explícitos.

Determinismo

Resultado reproducible para entradas equivalentes.

EvaluaciónPropiedades de calidad

Corrección, eficiencia y claridad

Corrección

Produce la salida especificada para todas las entradas válidas.

Eficiencia

Minimiza el tiempo de ejecución y el uso de memoria.

Claridad

Usa nombres, pasos y estructuras comprensibles.

calidad = corrección + terminación + claridad + eficiencia

Nivel 01Lenguaje natural

Representación en lenguaje natural

Descripción textual de las entradas, operaciones, condiciones y salidas del algoritmo.

Leer tres notas, calcular su promedio y mostrar “Aprobado” si el promedio es mayor o igual a 61; de lo contrario, mostrar “Reprobado”.

Ventaja

Lectura sin conocimientos de programación.

Limitación

Posibilidad de ambigüedad.

Uso

Definición inicial del procedimiento.

Algoritmo EstadoCurso

    SiNo

    FinSi
FinAlgoritmo

Estructuras condicionalesSelección

Tipos de estructuras condicionales

Una condición es una expresión lógica formada por valores, variables, operadores relacionales y operadores lógicos.

Simple

Ejecuta un bloque cuando la condición es verdadera.

Doble

Selecciona entre bloque verdadero y bloque falso.

Múltiple

Selecciona entre tres o más alternativas.

relacionales: =, ≠, <, >, ≤, ≥ · lógicos: Y, O, NO

Ejemplo 1: área de un rectángulo

Algoritmo AreaRectangulo
    Definir base, altura, area Como Real

    Escribir "Base:"
    Leer base
    Escribir "Altura:"
    Leer altura

    area <- base * altura
    Escribir "Area: ", area
FinAlgoritmo

Ejemplo 2: mayoría de edad

Algoritmo MayorDeEdad
    Definir edad Como Entero

    Escribir "Ingrese la edad:"
    Leer edad

    Si edad >= 18 Entonces
        Escribir "Mayor de edad"
    Sino
        Escribir "Menor de edad"
    FinSi
FinAlgoritmo

Evaluación

Condición: edad >= 18

Verdadero: ejecuta el primer bloque.

Falso: ejecuta el bloque Sino.

Caso límite: edad = 18.

Ejemplo 4: ciclo Mientras

Algoritmo ContarHastaCinco
    Definir contador Como Entero
    contador <- 1

    Mientras contador <= 5 Hacer
        Escribir contador
        contador <- contador + 1
    FinMientras
FinAlgoritmo

Componentes del ciclo

Inicialización: contador ← 1.

Condición: contador <= 5.

Actualización: contador ← contador + 1.

Salida: 1, 2, 3, 4, 5.

Ejemplo 5: costo de envío

Algoritmo CostoEnvio
    Definir peso, distancia, subtotal Como Real
    Definir recargo, total Como Real
    Definir urgente Como Logico

    Leer peso, distancia, urgente
    subtotal <- 20 + peso * 3 + distancia * 0.25

    Si urgente Entonces
        recargo <- subtotal * 0.20
    Sino
        recargo <- 0
    FinSi

    total <- subtotal + recargo
    Escribir "Subtotal: Q", subtotal
    Escribir "Recargo: Q", recargo
    Escribir "Total: Q", total
FinAlgoritmo
ENTRADApeso = 4 · distancia = 20 · urgente = Verdadero
SUBTOTAL20 + 4 × 3 + 20 × 0.25 = Q37
RECARGOQ37 × 0.20 = Q7.40
TOTALQ44.40
