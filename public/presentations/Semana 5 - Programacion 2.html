Integridad

Actuar con honestidad también significa no esconder errores de diseño: validar entradas, declarar límites y construir estructuras que otra persona pueda comprender y verificar.

En un TDA: encapsular no es ocultar problemas; es proteger invariantes. Si una lista es circular, su último nodo debe apuntar al primero siempre, o reportar con claridad que está vacía.

Honestidad

No prometer acceso O(1) cuando se recorre la estructura.

Seguridad

Validar índices, archivos y datos antes de operar.

Confiabilidad

Conservar las reglas internas después de cada método.

Invariantes internas

Reglas que todo método debe conservar.

  • vacía → primero y último son null;
  • un nodo → primero = último;
  • circular → último.Siguiente = primero.

Listas nativas de C#List<T>

Una lista ordenada, dinámica y tipada.

var cursos = new List<string>
{
  "IPC2", "Estructuras"
};
cursos.Add("Bases de datos");
cursos.Remove("IPC2");
foreach (string curso in cursos)
  Console.WriteLine(curso);

Preguntas de diseño

  • ¿Necesito conservar el orden? Sí.
  • ¿Necesito acceder por posición? Sí: cursos[0].
  • ¿Inserto mucho al inicio? Considera una lista enlazada propia.

List<T> es excelente por defecto, pero no reemplaza todos los TDA.

DiccionariosClave → valor

Cuando conoces la clave, no necesitas recorrer toda la lista.

var nombres = new Dictionary<string, string>();
nombres["202300376"] = "Jorge";
if (nombres.TryGetValue("202300376", out string? nombre))
  Console.WriteLine(nombre);
else
  Console.WriteLine("Carnet no encontrado");

Integridad aplicada

TryGetValue evita asumir que la clave existe. Es más seguro cuando el dato viene de un archivo, formulario o servicio externo.

Claves: únicas y estables. Valores: datos asociados a esa identidad.

¿Tupla o clase?

Usa una tupla para un resultado pequeño y temporal. Usa una clase o record cuando el concepto tiene comportamiento, reglas o será central en el dominio.

Una tupla no sustituye un TDA.

Idea clave

El último nodo referencia otra vez al primero. Para recorrer sin bucle infinito se define un inicio y se detiene al regresar a él.

Uso real

Turnos rotativos, reproductores en ciclo, planificación round-robin y jugadores que toman turnos.

Ejemplo · lista circularNodo + enlace

La operación crítica conserva el ciclo.

public void Insertar(string valor)
{
  Nodo nuevo = new(valor);
  if (primero is null) {
    primero = ultimo = nuevo;
    nuevo.Siguiente = nuevo; // un nodo se enlaza consigo mismo
    return;
  }
  nuevo.Siguiente = primero;
  ultimo!.Siguiente = nuevo;
  ultimo = nuevo;
}
Invariante después de insertar: ultimo.Siguiente == primero. Si no se cumple, ya no existe una lista circular confiable.

Enlaces

Cada nodo puede guardar Derecha y Abajo; según el diseño, también Izquierda y Arriba.

Casos

Tableros, asientos, mapas dispersos y matrices donde no conviene almacenar todas las posiciones vacías.

Ejemplo · matriz enlazadaClase nodo

Dos referencias abren un recorrido bidimensional.

public class NodoMatriz<T>
{
  public T Dato { get; }
  public NodoMatriz<T>? Derecha { get; set; }
  public NodoMatriz<T>? Abajo { get; set; }
  public NodoMatriz(T dato) => Dato = dato;
}

Conectar (0,0) con sus vecinos

a.Derecha = b;
a.Abajo = c;

El desplazamiento ocurre siguiendo referencias entre objetos.
